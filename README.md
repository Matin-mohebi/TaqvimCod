# تقویم 📅

<div dir="rtl">

**تقویم فارسی برای اندروید و iOS؛ با تاریخ شمسی، میلادی و قمری، مناسبت‌های ایران و مدیریت رویدادهای تقویم دستگاه.**

نام نمایشی برنامه: **تقویم**

</div>

## امکانات

- تقویم شمسی (جلالی) با محاسبه سال‌های کبیسه
- نمایش تاریخ‌های شمسی، میلادی و قمری
- تعطیلات رسمی و مناسبت‌های ایران
- خواندن، افزودن، ویرایش و حذف رویدادها از طریق تقویم سیستم، با اجازه کاربر
- ویجت صفحه اصلی در اندروید
- پرش مستقیم به ماه و سال شمسی دلخواه با لمس عنوان ماه
- نمایش ساعت زنده دستگاه با به‌روزرسانی هر ثانیه و تازه‌سازی خودکار تقویم هنگام تغییر روز
- نگه‌داشتن لمس روی تاریخ انتخاب‌شده برای کپی هم‌زمان تاریخ شمسی، میلادی و قمری
- ساخت خودکار APK آزمایشی و اجرای تست‌های واحد از طریق GitHub Actions
- تم روشن، تاریک و خودکار
- رابط فارسی راست‌چین و پشتیبانی از زبان‌های برنامه
- تنظیمات محلی رمزنگاری‌شده در اندروید
- نسخه بومی iOS با SwiftUI در پوشه `ios/`

## دریافت نسخه اندروید

1. وارد بخش [نسخه‌ها (Releases)](../../releases) شوید و اگر نسخه‌ای منتشر شده است، فایل نصب را دریافت کنید.
2. برای دریافت نسخه آزمایشی، از بخش **Actions** اجرای گردش‌کار ساخت را بررسی کنید و در صورت موفقیت، فایل خروجی را از **Artifacts** همان اجرا بگیرید.

> برای خواندن و مدیریت رویدادها باید مجوز تقویم دستگاه را به برنامه بدهید. فقط برنامه را از منبعی دریافت کنید که به آن اعتماد دارید.

## ساخت نسخه اندروید از کد منبع

پیش‌نیازها: JDK 17 یا جدیدتر و Android SDK مناسب پروژه.

```bash
git clone https://github.com/Matin-mohebi/TaqvimCod.git
cd TaqvimCod
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

برای ساخت نسخه Release:

```bash
./gradlew assembleRelease
```

اگر کلید امضای خصوصی به‌صورت امن پیکربندی نشده باشد، خروجی Release ممکن است امضانشده باشد. فایل keystore، رمزها و کلیدهای دسترسی را در مخزن قرار ندهید. برای امضای خودکار در GitHub Actions از **Settings → Secrets and variables → Actions** و متغیرهای موردنیاز گردش‌کار استفاده کنید.

## ساخت نسخه iOS

ساخت نسخه iOS به macOS و Xcode سازگار با پروژه نیاز دارد. راهنمای موجود در [راهنمای نسخه iOS](ios/README.md) را ببینید.

## حریم خصوصی و امنیت

- برنامه اندروید مجوز مستقیم اینترنت درخواست نمی‌کند.
- رویدادها از طریق ارائه‌دهنده تقویم خود دستگاه خوانده و ذخیره می‌شوند. اگر تقویم انتخاب‌شده به یک سرویس ابری متصل باشد، همگام‌سازی آن تابع تنظیمات حساب و دستگاه است.
- تنظیمات امنیتی و جزئیات پردازش داده‌ها در [سیاست حریم خصوصی](PRIVACY.md) توضیح داده شده‌اند.
- برای گزارش مسئولانه آسیب‌پذیری، [سیاست امنیتی](SECURITY.md) را بخوانید.

## گزارش مشکل و مشارکت

برای گزارش خطا یا پیشنهاد بهبود، در بخش **Issues** مخزن یک مورد ثبت کنید و مراحل بازتولید مشکل، نسخه اندروید/iOS و پیام خطا را بنویسید. اطلاعات شخصی، رمزها، کلیدهای خصوصی یا توکن‌های دسترسی را در گزارش‌ها قرار ندهید.
