## ✦ دربارهٔ پروژه

**تقویم (Taqvim)** یک تقویم فارسی برای Android با رابط راست‌چین، تاریخ‌های چندگانه و ابزارهای کاربردی روزانه است. پروژهٔ iOS نیز در پوشهٔ `ios/` نگه‌داری می‌شود. هدف این پروژه فقط نمایش روزها نیست؛ رویدادهای تقویم دستگاه، تعطیلات، شمارش معکوس مناسبت بعدی و ابزارهای اوقات شرعی هم در یک تجربهٔ منسجم کنار هم قرار می‌گیرند.

> نسخهٔ کد فعلی: **Android 1.6.0** · کد نسخهٔ اندروید: **8**

## 📲 دریافت APK

ساخت خودکار روی GitHub Actions انجام می‌شود. برای دریافت APK:

1. وارد [آخرین اجراهای ساخت](https://github.com/Matin-mohebi/TaqvimCod/actions/workflows/build.yml) شوید.
2. آخرین اجرای دارای وضعیت **Success** را باز کنید.
3. در پایین صفحه، از بخش **Artifacts** فایل `TaqvimCod-APK` را دانلود کنید.
4. ZIP را باز کنید و APK داخل آن را نصب کنید.

**توجه:** فایل Debug برای آزمایش است و جای نسخهٔ Release امضاشده را نمی‌گیرد. تا وقتی فایل در [Releases](https://github.com/Matin-mohebi/TaqvimCod/releases) منتشر نشده، آن را نسخهٔ پایدار رسمی در نظر نگیرید. APK نسخهٔ Debug ممکن است برای نصب روی نسخهٔ قبلی به امضای یکسان نیاز داشته باشد.

## 🛠️ ساخت از سورس

**نیازمندی‌ها:** JDK 17، Android SDK و ابزارهای ساخت متناسب با پروژه.

```bash
git clone https://github.com/Matin-mohebi/TaqvimCod.git
cd TaqvimCod
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

فایل خروجی Debug پس از ساخت در مسیر زیر قرار می‌گیرد:

```text
app/build/outputs/apk/debug/app-debug.apk
```

برای ساخت Release:

```bash
./gradlew assembleRelease
```

برای انتشار قابل‌ارتقا، کلید امضای خصوصی را خارج از مخزن نگه دارید و مقادیر امضا را از طریق متغیرهای محیطی یا Gradle Properties به فرایند ساخت بدهید. هرگز keystore یا رمز آن را در GitHub commit نکنید.
