<div dir="rtl">

## امکانات نسخهٔ 1.2.0

- تقویم شمسی (جلالی) با محاسبهٔ سال‌های کبیسه
- نمایش تاریخ‌های شمسی، میلادی و قمری
- تعطیلات رسمی و مناسبت‌های ایران
- خواندن، افزودن، ویرایش و حذف رویدادها از طریق تقویم دستگاه، با اجازهٔ کاربر
- انتخاب مستقیم ماه و سال و کپی/اشتراک‌گذاری تاریخ‌ها
- ساعت زنده با به‌روزرسانی ثانیه‌ای
- صفحهٔ اوقات شرعی آفلاین با انتخاب روش محاسبه و مختصات شهر
- قبله‌نمای حسگرمحور با اصلاح تقریبی انحراف مغناطیسی
- یادآوری روزانهٔ اوقات شرعی با اعلان و زمان‌بندی مجدد پس از راه‌اندازی دستگاه
- ویجت جداگانهٔ اوقات شرعی در کنار ویجت تقویم
- تم روشن، تاریک و خودکار؛ رابط فارسی راست‌چین
- تنظیمات محلی رمزنگاری‌شده در اندروید
- تست‌های واحد و ساخت خودکار APK با GitHub Actions
- نسخهٔ بومی iOS با SwiftUI در پوشهٔ `ios/`

## دریافت آخرین نسخهٔ اندروید

**آخرین ساخت‌های پروژه:** [مشاهدهٔ GitHub Actions](https://github.com/Matin-mohebi/TaqvimCod/actions)

1. اجرای ساخت موفق را باز کنید.
2. در بخش **Artifacts**، فایل APK مربوط به همان اجرا را دریافت کنید.
3. اگر خروجی به شکل ZIP است، آن را باز کنید تا APK داخل آن را بردارید.

> خروجی‌های Actions آزمایشی و موقت‌اند. تا زمانی که نسخه‌ای در بخش Releases منتشر نشده، آن‌ها را با نسخهٔ پایدار و امضاشده اشتباه نگیرید. برای انتشار رسمی، به [صفحهٔ Releases](https://github.com/Matin-mohebi/TaqvimCod/releases) مراجعه کنید.

## ساخت نسخهٔ اندروید از کد منبع

پیش‌نیازها: JDK 17 یا جدیدتر و Android SDK مناسب پروژه.

```bash
git clone https://github.com/Matin-mohebi/TaqvimCod.git
cd TaqvimCod
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

برای ساخت نسخهٔ Release:

```bash
./gradlew assembleRelease
```

اگر کلید امضای خصوصی به‌صورت امن پیکربندی نشده باشد، خروجی Release ممکن است امضانشده باشد. فایل keystore، رمزها و کلیدهای دسترسی را در مخزن قرار ندهید. برای امضای خودکار در GitHub Actions از **Settings → Secrets and variables → Actions** و متغیرهای موردنیاز گردش‌کار استفاده کنید.

## حریم خصوصی و امنیت

- برنامهٔ اندروید مجوز مستقیم اینترنت درخواست نمی‌کند.
- رویدادها از طریق ارائه‌دهندهٔ تقویم خود دستگاه خوانده و ذخیره می‌شوند. اگر تقویم انتخاب‌شده به سرویس ابری متصل باشد، همگام‌سازی آن تابع تنظیمات حساب و دستگاه است.
- تنظیمات امنیتی و جزئیات پردازش داده‌ها در [سیاست حریم خصوصی](PRIVACY.md) توضیح داده شده‌اند.
- برای گزارش مسئولانهٔ آسیب‌پذیری، [سیاست امنیتی](SECURITY.md) را بخوانید.

## گزارش مشکل و مشارکت

برای گزارش خطا یا پیشنهاد بهبود، در بخش **Issues** مخزن یک مورد ثبت کنید و مراحل بازتولید مشکل، نسخهٔ اندروید/iOS و پیام خطا را بنویسید. اطلاعات شخصی، رمزها، کلیدهای خصوصی یا توکن‌های دسترسی را در گزارش‌ها قرار ندهید.
